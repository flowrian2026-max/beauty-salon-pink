# Beauty Salon pink

PROJECT: NOIR PINK — CINEMATIC 3D BEAUTY EXPERIENCE



YOUR ROLE:

Act as an award-winning creative director, senior product designer,

3D web designer, and expert frontend developer.



Create a premium, immersive, cinematic website for a modern

beauty salon brand called NOIR PINK.



This must NOT look like a generic AI-generated salon template.



The visual direction should be inspired by the reference video:

a dark futuristic atmosphere, dramatic lighting, bold typography,

floating 3D visuals, striking product composition, and sophisticated

motion design.



Adapt that visual language to a luxury beauty brand.



The result should feel like an expensive digital experience

created by a world-class creative studio.



==================================================

1. VISUAL ART DIRECTION

==================================================



Create a dark, cinematic, futuristic visual environment.



Use a nearly black background with carefully controlled neon pink

lighting and subtle deep-purple undertones.



COLOR PALETTE:

- Main background: #08080B

- Secondary background: #111018

- Elevated surfaces: #19151F

- Neon pink: #FF2D95

- Soft pink: #F5A4CA

- Deep rose: #C72D75

- Main text: #FAF7FA

- Secondary text: #AAA4B0

- Borders: #302431



Use CSS variables for all design tokens.



The website should feel:

- Cinematic

- Futuristic

- Premium

- Immersive

- Bold

- Elegant

- Sophisticated

- Visually distinctive



Pink should be used as a powerful accent, not as a solid

background across the entire website.



Use realistic photography, dramatic highlights, deep shadows,

subtle reflections, and layered compositions.



Avoid generic gradients, excessive glassmorphism, childish

pink aesthetics, repetitive cards, and unnecessary decorations.



==================================================

2. THE HERO — THE MOST IMPORTANT SECTION

==================================================



Build an impressive full-screen hero section.



The first screen must immediately communicate quality,

depth, and a strong creative identity.



COMPOSITION:

- Near-black cinematic background

- Large, bold typography

- One striking beauty visual as the focal point

- Layered visual elements

- Pink rim lighting

- Realistic shadows

- Subtle atmospheric glow

- Elegant navigation

- Clear call-to-action buttons

- Small animated scroll indicator



HEADLINE:



BEAUTY

WITHOUT LIMITS.



Supporting copy:



A new dimension of beauty.

Bold creativity. Exceptional detail. Unforgettable style.



Primary CTA:

BOOK YOUR EXPERIENCE



Secondary CTA:

EXPLORE THE WORLD



Place the headline and main visual in an asymmetric composition.

Avoid centering every element.



Use large typography that occupies a significant part of the screen.



The main visual should feel integrated into the environment,

with believable lighting and depth.



If a suitable 3D model is available, use it.



Otherwise, create depth using layered photography, CSS 3D transforms,

perspective, lighting, and subtle parallax.



Do not use a generic beauty stock image as a tiny card.



The hero must feel like a premium advertising campaign.



==================================================

3. MOTION DESIGN

==================================================



Create sophisticated motion throughout the website.



Include:

- Smooth entrance animations

- Scroll-triggered reveals

- Subtle parallax

- Perspective-based hover interactions

- Elegant image zoom

- Smooth button transitions

- Controlled pink light effects

- Subtle depth movement

- Refined section transitions



Use motion to guide attention.



Do not animate everything simultaneously.



Avoid excessive bouncing, spinning, flashing, or random movement.



Prefer lightweight CSS transforms and opacity transitions.



Respect prefers-reduced-motion.



Keep animations smooth on mobile devices.



==================================================

4. HEADER

==================================================



Create a minimal premium navigation bar.



Use a transparent dark appearance over the hero.



After scrolling, transition to a slightly more opaque background.



Include:

- NOIR PINK wordmark

- Services

- Experience

- Gallery

- About

- Contact

- Booking CTA



Use restrained uppercase typography and generous spacing.



Add a subtle neon pink highlight to the active navigation item.



Create a clean mobile menu.



==================================================

5. SERVICES — EDITORIAL LAYOUT

==================================================



Create an editorial services section titled:



THE ART OF TRANSFORMATION



Do not use a conventional grid of identical white cards.



Instead, use large photographic blocks, asymmetrical spacing,

dark surfaces, strong typography, and subtle depth.



Sample services:

- NAIL ART

- HAIR STYLING

- MAKEUP

- SKINCARE

- MANICURE

- PEDICURE



Each service should include:

- Image

- Title

- Short description

- Editable placeholder price

- Estimated duration

- Booking button



Clearly mark sample prices as replaceable placeholders.



Use subtle hover movement and elegant image transitions.



==================================================

6. BEFORE / AFTER EXPERIENCE

==================================================



Build a functional interactive before-and-after slider.



The customer must be able to drag a divider horizontally

to compare two images.



Requirements:

- Real draggable interaction

- Mouse and touch support

- Responsive layout

- Clear BEFORE and AFTER labels

- Smooth divider movement

- Accessible controls where practical



Use supplied photographs when available.



If no actual photographs are supplied, use replaceable

sample images and label them appropriately.



Do not fabricate customer transformations or claim

that sample results are real.



Present this section as a premium visual experience,

not as an ordinary comparison widget.



==================================================

7. GALLERY — IMMERSIVE VISUAL GRID

==================================================



Create a dramatic editorial gallery.



Use:

- Asymmetric image arrangements

- Large featured photography

- Mixed image proportions

- Subtle image scaling

- Dark overlays

- Pink highlights

- Smooth hover transitions



Add working filters for available categories:

ALL, NAILS, HAIR, MAKEUP, SKINCARE.



Only show categories that have corresponding gallery items.



Clicking an image should open an accessible lightbox.



The lightbox must support:

- Close

- Previous

- Next

- Keyboard navigation where practical



Use replaceable sample photography until actual salon

images are provided.



==================================================

8. BRAND STORY

==================================================



Create a sophisticated section titled:



BEYOND THE ORDINARY.



Use a split editorial layout with large imagery and concise copy.



The visual treatment should include subtle depth, careful spacing,

and a contrast between dark surfaces and illuminated details.



Do not invent a founder's identity, business history,

qualifications, awards, or years of experience.



Use editable placeholder text.



==================================================

9. BOOKING EXPERIENCE

==================================================



Build an interactive appointment booking interface.



The user should be able to:

1. Choose a service.

2. Enter their name.

3. Enter contact information.

4. Select a preferred date.

5. Choose a preferred time.

6. Review the selection.

7. Submit the form.



Validate the required fields.



Show helpful success and error messages.



For this prototype, bookings may be stored locally if supported.



Clearly explain that demo bookings are not sent to a real salon

unless a backend is actually connected.



Do not integrate paid booking services.



Make the booking interface visually consistent with the

cinematic dark theme.



==================================================

10. CONTACT

==================================================



Create a minimal, premium contact section.



Include editable fields for:

- Address

- Phone

- Email

- Opening hours

- Social media links



Do not invent real contact information.



Add a contact form with basic validation.



If no backend exists, explain that the form is a frontend demo

and cannot send messages externally.



==================================================

11. ADMIN DASHBOARD PROTOTYPE

==================================================



Create a separate admin interface for managing the demo website.



Include:

- Dashboard overview

- Services

- Pricing

- Gallery

- Before-and-after images

- Booking requests

- Contact information

- Brand appearance



Implement working frontend interactions where possible.



Allow the demo administrator to:

- Add and edit services

- Change sample prices

- Add and remove gallery entries

- Preview image replacements

- View demo bookings

- Edit contact details

- Change the accent color

- Preview visual changes



Persist demo changes locally where practical.



Do not claim that this frontend-only dashboard is secure.



Do not store secrets in client-side code.



A production admin system will require real authentication,

authorization, and backend persistence.



Do not add paid services during this prototype phase.



==================================================

12. RESPONSIVE DESIGN

==================================================



Design intentionally for:

- Mobile

- Tablet

- Laptop

- Desktop



The mobile version must feel like a premium design,

not a compressed desktop layout.



Ensure:

- No horizontal overflow

- Readable typography

- Touch-friendly controls

- Working navigation

- Proper image cropping

- Smooth performance

- Responsive comparison slider



==================================================

13. TECHNICAL IMPLEMENTATION

==================================================



Use the existing Lovable project environment and supported

framework rather than unnecessarily rebuilding the project.



Build reusable components.



Keep the code organized and maintainable.



Use CSS custom properties for colors and design tokens.



Avoid unnecessary dependencies.



Do not require paid APIs or paid integrations.



Do not add payment processing during the initial prototype.



Do not pretend that visual mockups are functional backend systems.



If real 3D rendering is implemented, make it genuinely interactive.

If CSS transforms are used, describe them as visual depth effects.



Optimize images and lazy-load content below the fold.



Make buttons, filters, sliders, menus, and forms actually work.



==================================================

14. FINAL QUALITY STANDARD

==================================================



Before finishing, check that:



- The hero is immediately impressive.

- The visual direction is consistent.

- The black and neon pink palette is controlled.

- Typography is bold and sophisticated.

- The composition is not generic.

- The main visual has convincing depth.

- Animations are refined and purposeful.

- The before-and-after slider works.

- Gallery filters work.

- The lightbox works.

- Forms validate input.

- The layout is responsive.

- Demo functionality is clearly distinguished from production.

- No paid integration is required.



Do not merely describe the design.



Implement the actual website in the existing project.



FINAL CREATIVE DIRECTION:



A dark, cinematic, neon-pink beauty experience inspired by

premium product advertising, futuristic visual storytelling,

editorial typography, dramatic lighting, and immersive depth.



The website should be memorable enough to serve as a portfolio

piece for a studio that creates premium next-generation websites.
